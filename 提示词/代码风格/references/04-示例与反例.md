# 示例与反例

本文件的示例全部抽象为通用业务场景，不绑定任何具体项目。

## 1. 编排函数 vs 大杂烩

### 反例

```go
func BuildApp(path string) (*App, error) {
    data, err := os.ReadFile(path)
    if err != nil {
        return nil, err
    }
    var raw RawConfig
    if err := yaml.Unmarshal(data, &raw); err != nil {
        return nil, err
    }
    if raw.Port == "" {
        raw.Port = "8080"
    }
    if raw.Timeout <= 0 {
        raw.Timeout = 30 * time.Second
    }
    db, err := sql.Open("postgres", raw.DSN)
    if err != nil {
        return nil, err
    }
    repo := NewRepository(db)
    svc := NewService(repo)
    return NewApp(raw, svc), nil
}
```

### 正例

```go
func BuildApp(path string) (*App, error) {
    raw, err := LoadConfig(path)
    if err != nil {
        return nil, err
    }

    cfg, err := ValidateConfig(raw)
    if err != nil {
        return nil, err
    }

    deps, err := NewDependencies(cfg)
    if err != nil {
        return nil, err
    }

    return NewApp(cfg, deps), nil
}
```

规则：编排函数只调用命名步骤；读文件、反序列化、补默认值、建连接、装配分别下沉。

## 2. 循环体抽函数

### 反例

```go
func BuildOrders(inputs []OrderInput) map[string]*Order {
    out := make(map[string]*Order)
    for _, in := range inputs {
        items := make([]Item, 0, len(in.Items))
        for _, item := range in.Items {
            items = append(items, Item{SKU: item.SKU, Qty: item.Qty})
        }
        out[in.ID] = &Order{ID: in.ID, Items: items}
    }
    return out
}
```

### 正例

```go
func BuildOrders(inputs []OrderInput) map[string]*Order {
    out := make(map[string]*Order, len(inputs))
    for _, in := range inputs {
        out[in.ID] = buildOrder(in)
    }
    return out
}

func buildOrder(in OrderInput) *Order {
    return &Order{ID: in.ID, Items: buildItems(in.Items)}
}

func buildItems(inputs []ItemInput) []Item {
    items := make([]Item, 0, len(inputs))
    for _, in := range inputs {
        items = append(items, Item{SKU: in.SKU, Qty: in.Qty})
    }
    return items
}
```

规则：循环体超过 15 行，或出现嵌套循环，就把内层抽成命名函数。

## 3. 深层嵌套 vs 守卫

### 反例

```go
func Process(req Request) error {
    if req.User != nil {
        if req.User.Active {
            if req.User.Role == "admin" {
                if req.Action != "" {
                    return doAction(req)
                }
            }
        }
    }
    return nil
}
```

### 正例

```go
func Process(req Request) error {
    if req.User == nil {
        return ErrUnauthorized
    }
    if !req.User.Active {
        return ErrForbidden
    }
    if req.User.Role != "admin" {
        return ErrForbidden
    }
    if req.Action == "" {
        return ErrInvalidRequest
    }
    return doAction(req)
}
```

规则：错误和边界先返回；正常路径保持在最外层。

## 4. else after return

### 反例

```go
if user, ok := users[id]; !ok {
    return nil, ErrNotFound
} else {
    result = user
}
```

### 正例

```go
user, ok := users[id]
if !ok {
    return nil, ErrNotFound
}
result = user
```

规则：`return` 后面不再写 `else`。

## 5. 泛名 vs 具体名

### 反例

```go
func handleData(data []byte) error
func process(req Request) error
func doCheck(cfg Config) error
func getData(id string) (*Entity, error)
```

### 正例

```go
func decodeRequest(data []byte) (Request, error)
func processOrder(req OrderRequest) error
func validateConfig(cfg Config) error
func findEntity(id string) (*Entity, error)
```

规则：函数名要能读出「做什么」；`Process` / `Handle` 只作为模块入口方法名。

## 6. 业务工具放错包

### 反例

```go
// pkg/tools/order.go
package tools

func BuildOrder(in OrderInput) *Order { ... }
func ValidatePayment(p Payment) error { ... }
```

### 正例

```go
// internal/order/build.go
package order

func Build(in OrderInput) *Order { ... }
func Validate(p Payment) error { ... }
```

规则：`pkg/tools` 不 import 业务包；带业务类型的函数留在业务包。

## 7. 错误散落 vs 哨兵

### 反例

```go
if user == nil {
    return errors.New("user not found")
}
if user.Blocked {
    return errors.New("user is blocked")
}
```

### 正例

```go
// pkg/errors/errors.go
var (
    ErrNotFound = errors.New("service: not found")
    ErrForbidden = errors.New("service: forbidden")
)
```

```go
if user == nil {
    return gerrors.ErrNotFound
}
if user.Blocked {
    return fmt.Errorf("%w: user %q is blocked", gerrors.ErrForbidden, user.ID)
}
```

规则：错误集中定义；需要上下文时用 `%w` 包装，不新建同义错误。

## 8. 魔法值 vs 常量

### 反例

```go
if len(items) > 100 {
    return ErrTooMany
}
time.Sleep(3 * time.Second)
```

### 正例

```go
const (
    DefaultPageSize = 100
    DefaultRetryWait = 3 * time.Second
)
```

```go
if len(items) > DefaultPageSize {
    return gerrors.ErrTooMany
}
time.Sleep(DefaultRetryWait)
```

规则：同一值只定义一次；默认值集中命名，不散落在函数体里。

## 9. 配置混层

### 反例

```go
type Config struct {
    Port string `yaml:"port"`
    DSN  string `yaml:"dsn"`
    DB   *sql.DB
    Repo *Repository
}
```

### 正例

```go
type RawConfig struct {
    Port string `yaml:"port"`
    DSN  string `yaml:"dsn"`
}

type Config struct {
    Port string
    DSN  string
}

type App struct {
    cfg  Config
    repo *Repository
}
```

规则：原始配置、校验后配置、运行时对象分开；运行时对象不参与反序列化。

## 10. log-and-return

### 反例

```go
func (s *Service) Do(ctx context.Context) error {
    if err := s.repo.Save(ctx, entity); err != nil {
        log.Printf("[service]save failed: %v", err)
        return err
    }
    return nil
}

func (h *Handler) Handle(ctx context.Context) error {
    if err := h.svc.Do(ctx); err != nil {
        log.Printf("[http]do failed: %v", err)
        return err
    }
    return nil
}
```

### 正例

```go
func (s *Service) Do(ctx context.Context) error {
    return s.repo.Save(ctx, entity)
}

func (h *Handler) Handle(ctx context.Context) error {
    if err := h.svc.Do(ctx); err != nil {
        log.Printf("[http]do failed: %v", err)
        WriteError(h.w, err)
        return err
    }
    return nil
}
```

规则：错误在边界记录一次；中间层只包装和返回。

## 11. 表驱动测试

### 反例

```go
func TestCalculate(t *testing.T) {
    if CalculateTotal(nil) != 0 {
        t.Fatal("empty failed")
    }
    if CalculateTotal([]Item{{Qty: 2, Price: 10}}) != 20 {
        t.Fatal("single failed")
    }
    if CalculateTotal([]Item{{Qty: 2, Price: 10}}) != 18 {
        t.Fatal("discount failed")
    }
}
```

### 正例

```go
func TestCalculateTotal(t *testing.T) {
    cases := []struct {
        name  string
        items []Item
        want  int
    }{
        {"empty", nil, 0},
        {"single", []Item{{Qty: 2, Price: 10}}, 20},
        {"with discount", []Item{{Qty: 2, Price: 10}}, 18},
    }

    for _, c := range cases {
        t.Run(c.name, func(t *testing.T) {
            if got := CalculateTotal(c.items); got != c.want {
                t.Errorf("CalculateTotal() = %d, want %d", got, c.want)
            }
        })
    }
}
```

规则：用例有名字、有 got/want；新增场景只加一行。
